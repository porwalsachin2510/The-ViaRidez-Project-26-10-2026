1. Scope of This Build

SCOPE: This is a website-only build. ViaRidez already has web and mobile booking/tracking applications being built separately and will connect them to this site later. This document does NOT include a client portal, booking engine, live tracking, or rider/driver apps — it covers only the informational, SEO-optimized corporate website: every service, every page, fully written and structured content, and the technical foundation for search visibility.

The site's job is to be ViaRidez's single most important SEO asset and lead-generation front door — the place a prospect (corporate HR/procurement buyer, event planner, or individual renting a bus) lands from Google, decides ViaRidez is credible, and either submits an enquiry or clicks through to the booking app once that's connected.

Future integration point

The only thing the developer needs to prepare for later app integration is: consistent, prominent "Book Now" / "Get a Quote" / "Client Login" call-to-action buttons across the site that currently point to a contact/enquiry form, but are built so the link target can be swapped for the live app/portal URL later with a single config change — not a page rebuild. No API work, backend booking logic, or account system is in scope here.

Rank ViaRidez at the top of Google for its core Dubai/UAE transport search terms — this is the #1 success measure for this project (see Section 6–9).

Give every service line its own fully written, keyword-targeted page — no service should be a bullet point buried on the homepage.

Convert corporate (B2B) visitors as the primary audience, while still giving B2C, MICE, and tourism visitors a clear, fast path.

7. On-Page SEO Requirements

7.1 Every page must have

A unique title tag (50–60 characters) built as: [Primary Keyword] | ViaRidez — e.g. "Employee Shuttle Service Dubai | ViaRidez"

A unique meta description (140–160 characters) that includes the primary keyword and a clear reason to click

Exactly one H1 per page, containing the primary keyword, matching (not necessarily identical to) the title tag

A logical H2/H3 hierarchy — no skipped levels, no headings used purely for visual styling

Descriptive, keyword-relevant alt text on every image (not "image1.jpg" or empty alt attributes)

Internal links from every service page to at least 2–3 related pages (e.g. Employee Shuttle → Fleet: Minibuses, → Free Zone Shuttle, → Case Studies)

A short, clean URL slug matching the primary keyword (e.g. /services/employee-shuttle-dubai, not /page?id=42)

7.2 CMS requirement

The CMS must expose title tag, meta description, H1, and URL slug as editable fields per page — not hard-coded in the template — so ViaRidez's team (or an SEO contractor) can adjust them post-launch without a developer.

8. Technical SEO Requirements

Core Web Vitals: Largest Contentful Paint under 2.5s, Cumulative Layout Shift under 0.1, measured on a standard 4G mobile connection — this is a direct Google ranking factor, not just a UX nicety.

Mobile-first responsive build, tested at 375px, 768px, 1024px, 1440px breakpoints; the majority of Dubai transport searches are mobile.

XML sitemap auto-generated and submitted to Google Search Console and Bing Webmaster Tools at launch.

robots.txt correctly configured — no accidental blocking of service or blog pages.

Canonical tags on every page to prevent duplicate-content issues (a common problem with WordPress + Elementor builds like the current site).

HTTPS/SSL across the entire site, no mixed-content warnings.

Structured data (schema.org markup) implemented per page type:

  → Organization + LocalBusiness schema sitewide (name, logo, address, phone, hours)

  → Service schema on every service page

  → FAQPage schema on pages with an FAQ block

  → BreadcrumbList schema for navigation trail

  → Review/AggregateRating schema once real client reviews are collected — do not fabricate ratings

hreflang tags correctly configured across English and Arabic versions of every page (see Section 12).

Full 301 redirect map from every existing viaridez.ae URL to its new equivalent, executed and verified before DNS cutover, to preserve whatever current search equity the live site has.

Google Search Console and Bing Webmaster Tools connected and verified from day one.



9. Local SEO Requirements (Dubai + Kuwait)

For a transport company, local search visibility (the Google Maps "local pack") is often more valuable than generic organic ranking — this is where a company actively searching for a service right now finds and calls a provider.

9.1 Google Business Profile

Fully complete Google Business Profile for the Dubai office (Business Bay) and Kuwait office — business name matching the real legal/trading name exactly, correct category, complete service list, opening hours including UAE public holidays.

Complete all services and attributes in both Arabic and English — required for full visibility in the UAE market.

Post at least one Google Business Profile update per week post-launch (offers, new routes, client wins) — this is an ongoing task for ViaRidez's team or marketing contractor, not a one-time developer task, but the site's blog content should feed these posts.

9.2 NAP consistency

Name, Address, and Phone number must be letter-for-letter identical across the website footer, every location page, Google Business Profile, and every directory listing — inconsistent NAP actively suppresses map ranking.

9.3 Local citations / directories

List ViaRidez on the key UAE business directories: YellowPages.ae, Connect.ae, 2GIS (important for UAE map/navigation search), and the Dubai Chamber business directory, plus any transport-industry-specific directories.

9.4 On-site local signals

Embedded Google Map on the Contact page and each Locations sub-page, matching the GBP-listed address exactly.

LocalBusiness schema (Section 8) carrying the same NAP data.

Location-specific content on the Free Zone Shuttle page (JAFZA, DIFC, Dubai South, DMCC) — these read as strong local-intent landing pages if built out properly, not just a bullet list.

11. Design & Branding Requirements

Full English/Arabic bilingual site — true mirrored RTL layout for Arabic, not a machine-translated overlay; this also directly supports the Local SEO requirement in Section 9.1.

Mobile-first responsive design across all breakpoints.

Confirm whether the current ViaRidez logo/color palette carries forward as-is or this project includes a brand refresh (open decision, Section 16).

Commission real fleet and driver photography in Dubai — the current site leans on generic stock-style imagery, which undercuts the "verified drivers, real fleet" trust message the copy makes, and generic stock images also carry no unique SEO/image-search value.

Target WCAG 2.1 AA accessibility as a minimum bar.

12. Technical & CMS Requirements

A CMS the ViaRidez team can self-edit without a developer — including the SEO fields in Section 7.2. WordPress is acceptable and keeps continuity with the current build; a modern headless CMS is also viable if the agency prefers strong Core Web Vitals performance out of the box.

Retain www.viaridez.ae as the primary domain; execute the full 301 redirect map (Section 8) before cutover.

Cloud hosting with a CDN (e.g. Cloudflare) for performance; consider UAE-region or nearby edge presence for latency, which also helps Core Web Vitals scores for local visitors.

Valid SSL/TLS on all environments, including staging.

Build all primary CTAs ("Get a Quote", "Book Now", "Client Login") as centrally configurable links — not hard-coded per page — so they can be repointed to the separately-built booking app/portal later without a redesign.
